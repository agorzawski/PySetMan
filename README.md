## SetMan Client

Simple python client to interact with the `SetManService` `0.16.0`

### covered functionality in client
- get realms
- get contexts (of `realm`)
- get parameters of `realm` or `trimmable` that are `true|false`
- get settings / resident settings (of `realm`)
- send trim 
- drive all to drive resident contexts (for `realm`).
